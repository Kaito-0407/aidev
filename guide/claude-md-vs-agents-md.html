CLAUDE.mdとAGENTS.md・スキル・rulesの違い｜どれに何を書くか

結論：毎回守ってほしいことはCLAUDE.md、一部のファイルだけの決まりは .claude/rules/、手順の長い作業はスキルに書きます。AGENTS.mdは、CLAUDE.mdが無いときにCLAUDE.mdの代わりに読まれます。

違いの一覧

種類誰が書くかいつ読まれるか向いている内容
CLAUDE.md自分毎回のセッション開始時ビルドのコマンド、書き方の決まり、構成、「必ず〜する」ルール
AGENTS.md自分CLAUDE.mdが無いとき、その代わりに他のAIコーディングツールと共通の指示
.claude/rules/自分毎回、または paths に合うファイルを扱うときテーマ別・ファイルの種類別の決まり
スキル自分呼び出したとき、または関係があるとClaudeが判断したとき手順の長い作業
自動メモリClaude自動メモリがオンのセッション（MEMORY.mdの先頭200行または25KBまで）自分の好み、Claudeへの訂正

CLAUDE.mdとAGENTS.mdが両方あるとき

初期設定では、Claude CodeはCLAUDE.mdを優先します。

リポジトリの状態読まれるもの
AGENTS.mdだけがあるAGENTS.md
AGENTS.mdとCLAUDE.md（またはCLAUDE.local.md）があるCLAUDE.mdだけ
CLAUDE.mdの中で AGENTS.md を読み込んでいるCLAUDE.mdと、読み込んだAGENTS.md

注意点：

  • CLAUDE.local.md もCLAUDE.mdとして数えられます。AGENTS.mdで運用しているプロジェクトに自分用のCLAUDE.local.mdを足すと、AGENTS.mdが読まれなくなります。
  • ~/.claude/CLAUDE.md と .claude/rules/ は数えられず、AGENTS.mdと一緒に読まれます。
  • 両方読ませたいときは、/config の Project instructions を claude-md-and-agents-md にします。
  • AGENTS.mdを直接読むには Claude Code v2.1.277 以降が必要です。

他のAIツールと1つのファイルを共有する

AGENTS.mdを共通のファイルにして、CLAUDE.mdで読み込む方法が公式で紹介されています。Claude専用の指示はその下に書きます。

@AGENTS.md

## Claude Code

（Claudeだけに伝えたいこと）

何をどこに書くかの目安

  • 毎回必要な事実（コマンド、決まり、構成）：CLAUDE.md
  • 一部のフォルダやファイルの種類だけで使う決まり：.claude/rules/（paths を付ける）
  • 手順の長い作業：スキル（必要なときだけ読まれる）
  • どうしても止めたい操作：フックを使う。公式ドキュメントでは、CLAUDE.mdは強制される設定ではなく、確実に止めたい操作にはPreToolUseフックを使うよう書かれています
質問に答えて CLAUDE.md を作る（無料）
